# Pashupat Solutions — Healthcare Landing Page

React + Vite landing page for Pashupat Solutions, using the supplied SVG logo and brand palette.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## GitHub Pages

The repository includes `.github/workflows/deploy-pages.yml` and is configured for:

`https://chandan807.github.io/landing_page_pashupat/`

If Pages is not already enabled, open **Settings → Pages → Build and deployment → Source → GitHub Actions** once.

## Form

The UI validation and interactions are complete. Before collecting live leads, connect the submit handler in `src/main.jsx` to your approved backend, CRM, or email endpoint.
